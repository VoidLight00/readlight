# Golden Principles — ReadLight

## 1. Companion, Not Tool
ReadLight sits beside you while you read. It never interrupts, never demands.
The AI is a curious friend, not a professor. It asks "탐구할까요?" — not "여기 답이 있습니다."

## 2. Layer Discipline
Architecture layers are walls, not suggestions.
UI never touches AI. Domain orchestrates. Storage is pure data.
Violation = bug, not style issue.

## 3. Graceful Degradation
No API key? App works perfectly — just no AI insights.
No internet? Everything runs from localStorage.
The reading experience is the product. AI is a bonus.

## 4. ADHD-Friendly by Design
Streaks forgive (1 rest day/week). Goals are gentle ("read 20 pages today").
Gamification motivates without punishing. Missing a day doesn't destroy progress.

## 5. Immutability Always
Never mutate state. Spread, copy, return new objects.
Zustand actions return new state, never modify existing.

## 6. Korean First
All UI text in Korean. Technical terms (API, OCR) can stay in English.
Variable names and code in English. Comments in English.

## 7. Mobile First
Design for thumb. 44px minimum touch targets.
Dark mode is the default, not an option.
